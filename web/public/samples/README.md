# Documentos de ejemplo de la demo

Los botones "Prueba con…" de la página cargan estos archivos:

- `factura-electronica.pdf`: factura electrónica sintética (datos inventados, generada
  con `engine/tests/fixtures.py`).
- `precuenta-restaurante.jpg`: precuenta real de restaurante; nombres de cajera y
  mesera difuminados.
- `precuenta-inclinada.jpg`: foto inclinada de una precuenta con 10% de servicio;
  nombre, cédula y email del cliente difuminados.

Si reemplazas alguno, difumina antes cualquier dato personal.
